## Um Pouco de História Sobre JavaScript

Se você já está no mundo do JavaScript, provavelmente já ouviu falar sobre **ECMAScript**.

> O que é isso?

**ECMAScript** é uma especificação padronizada para linguagens de script definida pela ECMA-262, inspirada no JavaScript.

**ECMAScript** é na verdade o próprio JavaScript (chocante!), mas continuamos chamando de JavaScript por conveniência e hábito. Portanto, ECMAScript é o nome oficial da linguagem.

> NÓS USAMOS ECMASCRIPT, NÃO JAVASCRIPT.

![Pessoa surpresa](/images/blog/es6-es7-es8-surprise.gif)

---

## O que são ES7, ES8, ECMAScript 2018...

Como toda linguagem de programação, ela tem versões e é atualizada ao longo do tempo. Nosso querido ECMAScript também.

As versões do ECMAScript eram abreviadas como ES1, ES2, ES3, ES5 e ES6.

Desde 2016 oficialmente, as versões são nomeadas por ano (ECMAScript 2016, 2017, 2018, 2019, 2020, ...), mas você pode encontrar documentação ainda chamando de ES7, ES8, etc.

---

## Por que Preciso me Importar com Versões?

Como o ECMAScript é predominantemente executado em navegadores, a evolução dos navegadores nem sempre acompanha o desenvolvimento da linguagem.

É por isso que temos ferramentas como **Babel**, **Webpack**, **Turbopack**, **Rollup** e até **TypeScript**, que nos permitem escrever código moderno sem nos preocupar com compatibilidade de navegadores.

> Lembre-se de que essas ferramentas fazem muito mais do que apenas transformar código moderno em código antigo.

## Funcionalidades de Cada Versão do ECMAScript

Vou listar TODAS (pelo menos até onde encontrei) as funcionalidades implementadas em cada versão lançada.

Como são muitas funcionalidades, não vou me aprofundar em todas e colocarei um 🚀 para aquelas que gosto e/ou acho mais úteis.

## ES1 (ECMAScript 1997)

Também conhecido como ECMAScript 1997.

A primeira versão do ECMAScript foi lançada em 1997. Foi criada com base no JavaScript e incluía funcionalidades como variáveis, funções e instruções básicas de fluxo de controle.

---

## ES2 (ECMAScript 1998)

Também conhecido como ECMAScript 1998.

A segunda versão foi lançada em 1998. Contém apenas pequenas alterações em relação à primeira versão.

---

## ES3 (ECMAScript 1999)

Também conhecido como ECMAScript 1999.

- **Regular Expressions** 🚀
- **Adicionado try/catch** 🚀
- **Adicionado switch** 🚀
- Adicionado do-while

Funcionalidades básicas encontradas em quase todas as linguagens.

---

## ES4 (Nunca Lançado)

A quarta versão estava em desenvolvimento, mas acabou sendo abandonada por causa de desacordos sobre a direção da linguagem. 🤷‍♂️

---

## ES5 (ECMAScript 2009)

Após um longo período sem atualizações, finalmente temos uma atualização com muitas novidades.

Também conhecido como ECMAScript 2009.

- "use strict"
- `String[number]` 🚀

```javascript
const texto = "Hello world"
texto[0] // "H"
```

- Multiline strings
- **String.trim()** 🚀

```javascript
const texto = " Hello world "
texto.trim() // "Hello world"
```

### Array

- **Array.isArray()** 🚀

```javascript
const frutas = ["Banana", "Laranja", "Maçã", "Manga"];
const texto = "Hello world"

Array.isArray(frutas) // true
Array.isArray(texto) // false
```

- **Array forEach** 🚀

```javascript
function mostrar(value) {
  return console.log(value)
}

const numbers = [45, 4, 9, 16, 25];
numbers.forEach(mostrar);
```

- **Array map()** 🚀

```javascript
function somar5(value) {
  return value + 5
}

const numbers1 = [45, 4, 9, 16, 25];
const numbers2 = numbers1.map(somar5); // [ 50, 9, 14, 21, 30 ]
```

- **Array filter()** 🚀

```javascript
function maiorDeIdade(value) {
  return value > 18;
}

const idades = [45, 4, 9, 16, 25];
const mais18 = idades.filter(maiorDeIdade); // [ 45, 25 ]
```

- **Array reduce()** 🚀

```javascript
function somar(acumulador, atual) {
  return acumulador + atual;
}

const numbers = [45, 4, 10, 16, 25];
const sum = numbers.reduce(somar, 0); // 100
```

- Array reduceRight
- **Array.every()** 🚀

```javascript
function maiorDeIdade(value) {
  return value > 18;
}

const idades = [45, 4, 9, 16, 25];
const todosMais18 = idades.every(maiorDeIdade); // false
```

- **Array.some()** 🚀

```javascript
function maiorDeIdade(value) {
  return value > 18;
}

const idades = [45, 4, 9, 16, 25];
const todosMais18 = idades.some(maiorDeIdade); // true
```

- **Array.indexOf()** 🚀

```javascript
const frutas = ["Banana", "Laranja", "Maçã", "Manga"];
frutas.indexOf("Laranja"); // 1
```

- Array.lastIndexOf()

### JSON

```javascript
const user = '{"nome":"Alexandre", "idade":24}'
JSON.parse(user)
/* ^? {
  name: "Alexandre",
  idade: 24

```

- **JSON.stringify()** 🚀

```javascript
const user = {
  name: "Alexandre",
  idade: 24
}
JSON.stringify(user) // '{"nome":"Alexandre", "idade":24}'
```

### Outros

- **Date.now()** 🚀

```javascript
// timestamp
Date.now() // 1700318490184
```

- Date toISOString()
- Date toJSON()
- Getter e Setter properties
- Permite palavras reservadas como nomes de propriedade
- Object methods
- Object defineProperty()
- Function bind()
- **Permite trailing commas em Arrays e Objects** 🚀

## ES6 (ECMAScript 2015)

Também conhecido como ECMAScript 2015.

- **let e const** 🚀
- **Arrow functions (A maior de todas)** 🚀

```javascript
const numeros = [1, 2, 3, 4, 5]
const elevado2 = numeros.map((numero) => numero * numero) // [1, 4, 9, 16, 25]
```

- **Spread Operator (...)** 🚀

```javascript
const numbers = [23, 55, 21, 87, 56];
const maxValue = Math.max(...numbers); // 87
```

- **for/of loop** 🚀

```javascript
const carros = ["BMW", "Volvo", "Mini"];

for (let x of carros) {
}
```

- **Map** 🚀
- **Set** 🚀

```javascript
const numeros = [1, 2, 3, 1, 4, 3]

const removerDuplicatas = new Set(numeros) // Set {1, 2, 3, 4}
```

- **Classes** 🚀
- **Promises (Nasce o backend JavaScript)** 🚀

```javascript
const promise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve("3 segundos");
  }, 3000);
});

promise.then(v => console.log(v)) // Aparece depois de 3 segundos
```

- Symbol
- **Default Parameters** 🚀

```javascript
function soma(x, y = 10) {
  return x + y;
}
soma(5); // 15
```

- **Rest Parameters em Funções** 🚀

```javascript
function sum(...args) {
  let sum = 0;
  for (let arg of args) sum += arg;
  return sum;
}

sum(4, 9, 16, 25, 29, 100, 66, 77); // 326
```

- **String.includes()** 🚀

```javascript
const text = "Hello world";
text.includes("world") // true
```

- String.startsWith()
- String.endsWith()
- Array.from()
- Array keys()
- **Array find()** 🚀

```javascript
const numbers = [4, 9, 16, 25, 29];
numbers.find((number) => number === 16); // 16
```

- **Array findIndex()** 🚀

```javascript
const numbers = [4, 9, 16, 25, 29];
numbers.findIndex((number) => number === 16); // 2
```

- Novos Math Methods
  - **Math.trunc()** 🚀
  - Math.sign()
  - Math.cbrt()
  - Math.log2()
  - Math.log10()


- Novas Number Properties
  - Number.EPSILON

- Novos Number Methods
  - Number.isInteger()

- isFinite()
- **isNaN()** 🚀
- **Object entries** 🚀
- **Modules (import, export)** 🚀
- **Template String** 🚀

## ECMAScript 2021

- String.replaceAll()

- Logical Assignment Operators

```javascript

x &&= 2; // x = 2 (AND assignment)

let y = false;

```
